This is a Python-based ASCII Art Generator that converts letters, words, numbers, and special characters into colorful ASCII art displayed in the terminal.
The project allows users to select different text sizes and colors using a simple interactive menu.
It uses Colorama for colored output and works in a Windows terminal.

**Features**

Generate small ASCII letters

Generate big ASCII letters

Convert words into ASCII art

Supports numbers (0–9)

Supports special characters: @ # $ &

Choose from 7 different colors

Menu-driven interactive interface

**Technologies Used**

Python |
colorama library |
os module |
msvcrt (for keyboard input – Windows only)
